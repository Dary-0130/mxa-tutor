### D1:净化层 = Chunker 边界(不是 Parser / 不是出口)

**问题**:绝对路径污染跨多层,在哪一层 sanitize?

**选项**:
- α:Parser(`m_parser.py` / `slx_parser.py`)处统一改用相对路径 — **治本但跨 task,违反 TASK-208 范围**
- β:**Chunker(`_project_chunker.py`)边界统一 sanitize**(推荐)
- γ:ChatResponse / SourceRefDTO 出口 sanitize — **治标,持久层 chunks 表仍混合污染**

**决策**:**β 推荐**。

**理由**:
- Parser domain 输入是 `str(extracted_root / file_info.relative_path)`,upload_service 已是绝对路径,改 Parser 等于改 domain 契约,跨 task

### D5:`is_public_file_path()` invariant 谓词 + `contains_server_path_hint()` leak detector 拆分(v0.1.1 / P1-1)

**问题**:v0.1 把 `_FORBIDDEN_ROOT_HINTS = ("mxa-workspace", "uploads", "pytest-", "Temp", "AppData")` 作为 substring 检查塞进 `is_public_file_path()`,会误杀**学生工程内合法路径**:
- `data/uploads/input.mat`(工程内合法 uploads 目录)
- `temp/model_init.m`(工程内合法 temp 目录)
- `upload_signal.m`(纯字符串 upload 前缀变量)

**决策**:拆分为两个独立函数(GPT R1 P1-1)。

#### 5.1 `is_public_file_path(path: str) -> bool` — 只判路径形态

```python
def is_public_file_path(path: str) -> bool:
    """Invariant: public file_path 必须满足以下任一:
    
    1. 等于 OVERVIEW_SENTINEL("__project_overview__"):哨兵透传
    2. 满足全部:
       - 非空字符串
       - PureWindowsPath 和 PurePosixPath 双判定:均非 absolute
       - 无 Windows drive(`C:foo` drive-relative 也禁)
       - 无 `..` 段(避免跳出工程根)
    
    **不做内容判定**(不检测 `uploads` / `temp` / `appdata` 等 substring,避免误杀学生工程内合法目录)
    """
```

#### 5.2 `contains_server_path_hint(path: str) -> bool` — 独立 leak detector

```python
def contains_server_path_hint(path: str) -> bool:
    """检测路径是否含服务器路径泄露片段(用于验收 grep,非 invariant)。
    
    **使用组合字面**(不是单词 substring),避免误判学生工程内合法路径:
    - "mxa-workspace/uploads"(组合)— 学生工程不会有此路径片段
    - "pytest-of-"(前缀)— pytest 临时目录特征
    - "appdata/local/temp"(组合)— Windows AppData 临时目录特征
    
    Returns: True 即检测到服务器路径泄露
    """
```

### 1. `core/domain/file_paths.py`(新建,v0.1.1 / P1-1 拆分)

```python
"""Public file_path invariant + 哨兵常量 + leak detector。

P1-1 拆分:is_public_file_path 只判路径形态;contains_server_path_hint 独立 leak detector。
"""

from __future__ import annotations

from pathlib import PureWindowsPath, PurePosixPath

__all__ = ["OVERVIEW_SENTINEL", "is_public_file_path", "contains_server_path_hint"]

OVERVIEW_SENTINEL = "__project_overview__"

_FORBIDDEN_SEGMENTS = frozenset({"..", ""})


def is_public_file_path(path: str) -> bool:
    """Public file_path invariant 谓词 — 只判路径形态(P1-1)。
    
    满足以下任一:
    1. 等于 OVERVIEW_SENTINEL("__project_overview__"):哨兵透传
    2. 满足全部:
       - 非空字符串
       - PureWindowsPath 和 PurePosixPath 双判定均非 absolute
       - 无 Windows drive(`C:foo` drive-relative 也禁)
       - 无 `..` 段
    
    **不做内容判定**(P1-1):不检测 `uploads` / `temp` / `appdata` 等 substring,
    避免误杀学生工程内合法目录(如 `data/uploads/input.mat` / `temp/model_init.m`)。
    服务器路径片段检测在 contains_server_path_hint() 独立函数。
    
    Returns: True 即满足 invariant。
    """
    if not path:
        return False
    if path == OVERVIEW_SENTINEL:
        return True
    
    # 双 PurePath 双判定(避免单平台运行时偏差)
    if PureWindowsPath(path).is_absolute() or PurePosixPath(path).is_absolute():
        return False
    
    # drive-relative 防御(`C:foo` PureWindowsPath 非 absolute 但有 drive)
    if PureWindowsPath(path).drive:
        return False
    
    # 路径段防御
    normalized = path.replace("\\", "/")
    segments = normalized.split("/")
    if any(seg in _FORBIDDEN_SEGMENTS for seg in segments):
        return False
    
    return True


def contains_server_path_hint(path: str) -> bool:
    """检测路径是否含服务器路径泄露片段(用于验收 grep,非 invariant;P1-1 新增)。
    
    使用**组合字面**(不是单词 substring),避免误判学生工程内合法路径:
    - "mxa-workspace/uploads":mxa-tutor 服务器特征路径
    - "pytest-of-":pytest 临时目录特征(tmp_path_factory 默认前缀)
    - "appdata/local/temp":Windows AppData 临时目录特征
    
    Returns: True 即检测到服务器路径泄露。
    """
    lower = path.lower().replace("\\", "/")
    return any(
        marker in lower
        for marker in (
            "mxa-workspace/uploads",
            "pytest-of-",
            "appdata/local/temp",
        )
    )
```
