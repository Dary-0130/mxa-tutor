- **推荐初始方向(交 PM)**:**新建独立、版本化、结构化 run-state 通道,默认带有界状态元数据 + 有界指标,降采样序列仅在 PM 第一拍选择后才带**;**原始 CSV/MAT / 完整波形始终留本地**。

## run / session 状态语义(R1 二审 P0,本设计卡锁规则,不锁字段名)
b3 是**有状态**能力(跨轮),隐私风险从「单请求」升级为「会话记忆」。下列为**规范性规则**(行为结果现在锁定;不锁 `run_id` / `sequence` / HTTP 状态码等字段名):
1. 原始 run-state 真值**永远在客户端**;服务端只持有**用户确认过的有界快照及派生状态**。
2. 每次 re-run 生成**新的不可变 run 快照**;旧快照**不得被覆盖**。
3. 同一提交标识 + 同一内容的重试为**幂等**(返回同一逻辑结果);同一标识 + 不同内容为**冲突**(拒绝)。
4. **乱序到达的旧 run 不得改写当前会话上下文**——明确取舍:拒绝作为当前 run,仅可作历史记录接收。
5. session 内状态转移**串行化**;两个并发 run **不得同时成为"当前 run"**。
6. 已结束 / 过期 / 删除的 session **拒绝后续写入,不得因重试自动复活**;继续陪调必须**新建 session**。
7. 删除或 TTL 到期后,关联**快照、派生状态、可恢复索引一并失效**。
8. **不同用户 / 项目 / session 之间严格隔离**;派生状态不得进入长期 cache / 备份 / 分析日志。

## 数据边界 5 条 + 留存删除(roadmap §10.3,b3 必全实现;R1/R6 补落地形态)
| 既有边界 | 必须写明的落地形态 |
|---|---|
| 不上传完整工程 | 同时**禁止**原始 CSV/MAT、完整 workspace dump、完整 Scope 导出 |
| 显式确认 | **每一轮**确认冻结后的确切 run-state 快照,不是仅首次授权 |
| 最小 payload | 限 series 数 / 每条点数 / 总字节 / 标签长度;拒非有限数值或明确编码 NaN/Inf |
| token scoped | 至少 scoped 到 用户 + 项目 + session + capability,短期有效、可撤销 |
| 日志限制 | 不记数值序列 / 模型标签 / 路径 / 源码;只记大小 / 类型 / 点数 / 状态码等元数据 |
| **留存与删除(新增,R1 P1)** | 服务端派生 session/run 状态须有 **TTL**;session 结束或用户删除后**清除**;不进长期 cache / 备份 / 分析日志 |

**非可信文本(R1/R6 P1)**:MATLAB 标签 / 变量名 / 注释仍是非可信输入,须**限长 + 脱敏**,并作为**数据而非指令**进入 prompt。

**实现前不变量(R1 二审 P1)**:
- **数值语义**:单位 / 时间基准 / 采样顺序缺失时**必须标记未知**,LLM **不得自行推断**。
- **降采样语义**:方法**确定、可复现**,并**声明是否保留峰值 / 极值**;不得由客户端任意算法静默改变曲线含义。
- **载荷形态**:**明确禁止**原始二进制 / base64 文件 / 压缩附件 / 任意嵌套 MATLAB 对象**借结构化字段绕过**"禁止原始 CSV/MAT"。

## b3 总门(roadmap §5.6 / §10.3;不达标不进 v0.4)
- **真实场景调通率 ≥50%** + **评测 v0.3 case ≥5 个、覆盖 6 类至少 3 类**——**这两个数值已锁**(roadmap/PM,非待真实 case 后再定)。
- 本卡**只不锁子维度分值 / 权重 / 人工评分量表**(随质量评估 seam,PM 定 + R1/R6 审);**总门 50% 与覆盖门已锁**。
- **整数阈值口径(R1 二审)**:成功数门 = `ceil(0.5 × 有效 case 数)`;故最少 5 个有效 case 时**至少成功 3 个**。
- **b3-3 前必须操作化(否则 50% 不可复现、易因排除规则不同漂移)**:① **case 集与排除规则在看结果前冻结**,禁止事后剔除失败 case;② 什么算「卡点闭环解决」;③ 最多允许多少轮;④ 分母是否含环境失败 · 用户中止 · 数据不足;⑤ 谁作最终人工裁定;⑥ 同一 case 多次尝试如何计数。
