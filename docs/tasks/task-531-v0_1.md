## 1. 目标与范围
放宽两处**纯内部常量**长度上限:论文原文门槛 `MAX_PAPER_RAW_TEXT_CHARS`、spec 生成预算 `DEFAULT_PAPER_SPEC_MAX_TOKENS`。
**本卡只动这两个常量。** `DEFAULT_PAPER_PLAN_MAX_TOKENS`(plan/guidance)**不动**、保持 8000(理由见 §5);`build_guidance_generator.py` 的 `DEFAULT_GUIDANCE_MAX_TOKENS=6000`(R6 指出)也**不碰**。
二者均不属对外 schema、不进 `schemas/*.json`、不触发决策 13;**不引入分段/截断续写等新机制**(那是撑爆模型窗口的超长文档才需要,现离两个数量级)。

## 2. 背景与已坐实事实
TASK-530 修好 PDF 活动内容闸后,8 篇真 arXiv 越闸,评测试车道复跑暴露 spec 生成层瓶颈。诊断(决策 15)分三处上限:两处内部常量(本卡)+ 一处对外 schema 字段(TASK-532)。
- 主路实际调 `deepseek-v4-flash`(**非**注释所写 V3;R6 已核);官方上下文窗口 1M token、单次最大输出 384K token。
- 现 80,000 字符门槛 ≈ 24,000 token;8,000 输出预算离 384K 极远。两处均为自设保守值。

## 3. 上限 A:论文原文门槛(80_000 → 150_000)
- 现值 `80_000`,`paper_spec_service.py:44`;拦截 `:134-135`(超即 `document_too_long_for_v0_1`)。
- 8 篇实测:最大 82,027(2409.11267)、中位 ~55,375;仅 2409 超门槛 2,027 字符。
- **PM 已拍:80_000 → 150_000。**
- ★ 措辞纪律(P2-2):150,000 只代表**允许进入**当前整篇抽取路径。当前真实质量回归仅覆盖到约 82,000 字符;更长文档的抽取质量分布**继续通过 telemetry 观察**,本卡**不声称**"150,000 字论文质量已实测"。不因此引入分段。

## 4. 上限 B:spec 生成预算(8000 → 16000)
- 现值 `8000`,`paper_spec_service.py:43`;传 LLM `:156`。
- 3 篇(2107.02719 / 2410.04316 / 2605.27553)历史撞 8000、`finish_reason=length`、残缺 JSON。
- 16k 临时复跑完整 spec 输出:最大 6,799、中位 ~4,081;**有随机展开波动**(历史撞 8000,16k 复跑未复现超 8k)——单次成功不足证 8k 够,故留 buffer。
- **改 8000 → 16000**(约实测最大 2.4×,罩波动)。
- ★ 成本面(采纳 R1-3,删除原"设更大无害"表述):抬 `max_tokens` 不强制模型吐满,但**扩大**最坏输出成本、最坏响应时间、与结构化重试叠加的最坏调用预算、provider/后台 job timeout 压力、病态话痨可继续生成的空间。故本卡须确认:
  - provider/client timeout 容得下 16000 输出;
  - 后台 job wall-clock 容得下;
  - 若已有结构化重试,算清最坏调用次数乘积不越 timeout。

## 5. plan/guidance 预算:本卡不抬(采纳 R1-3 裁决)
原倾向一并抬 `DEFAULT_PAPER_PLAN_MAX_TOKENS`(8000)。**改为不抬,保持 8000**,理由:
- build_steps 实测输出仅 3,988 / 4,769、**无 `finish_reason=length` 证据**;spec 的随机撞线不能外推到 plan/guidance 这个不同生成阶段;
- 该常量同时影响 plan 与 guidance(且 R6 指出 guidance 侧另有 `DEFAULT_GUIDANCE_MAX_TOKENS=6000` 被 `PaperPlanService` 覆盖的关系)——blast radius 大于"一处数字";
- 本卡已有 raw gate + spec budget 两个**已证实**修复点,再顺带加未发生问题会削弱归因与回滚边界。
**改为提前设触发条件**(不被动等用户撞):任意一次 plan/guidance `finish_reason=length`、或样本窗口内 P95 输出明显逼近 8000、或真实 guidance 分布证明 8000 缓冲不足 → **届时另起小卡**;若那时确认 plan 与 guidance 共享同一常量,优先拆成阶段独立预算,不用一个数控制不同输出。
