## 3. 改动 + 关键设计点

### 3.1 放宽 max_length
`abstract` `max_length`:1000 → **1500**(PM 已拍;撞线最长 1162,给未来更长综合摘要留余量)。**字符串超长仍 fail**,**不**静默截到 1500(决策 17:列表可严格降级、字符串截断破坏语义仍 fail)。

### 3.2 第一层防线:prompt 指令(★ 必改,非"确认")
**R6 查明:现有 prompt 仅 "abstract: 1-1000 字,概括资料任务和物理含义",无任何 "综合非照抄 / 不要照抄第一段" 句子。** 故不是把 `1-1000` 机械改成 `1-1500`,而是**新写**明确指令,区分:
- **推荐目标长度**:显著低于硬上限,按现有样本校准在约 **300–800 字**区间(勿把 1500 暗示成目标长度);
- **绝对硬上限**:1500(异常长但合法输出的保险线);
- **结构要求**:研究问题 / 方法或建模对象 / 关键方程或参数线索 / 复现目标;
- **表达要求**:必须用自己的表述综合,**不逐句翻抄论文 abstract、不复制完整源句或整段**。

### 3.3 第二层防线(整段复制硬检测):★ 拆为独立后续卡,本卡不做
R1-4 指出:1500 装得下整段原摘要,仅 prompt 只能**降低概率、不能作为可验证硬防线**。正解需一个**窄的**"整段/整句复制检测 + 有界重写"backstop。**但本卡不建**,理由:它是独立机制(规范化比对 + 长片段检测 + 命中重写 + 独立原因码 + 校准 + 整套测试矩阵),blast radius 与验收口径都与"放宽上限"不同,塞进来即"一张卡两件事"、混淆归因与回滚;且它**不是**放宽上限让那 2 篇正经综合摘要通过的阻塞前提。
→ **拆独立后续卡(编号待定),且先诊断**:先量现有 8 篇 abstract 与源 raw_text 的重叠度、照抄现象实际严重度,再定检测阈值与重写边界(单字段重写 vs 整份重生成须在该卡明确选定)。
- **本卡因此老实声明**:本卡使 prompt **尽量减少**照抄,**不声称**"防照抄已由 prompt 兜住"。此声明写入卡与 PR 说明,不虚假拔高。
