## 3. PM 已拍板字段决策(4 维)

PM 与架构师 2026-06-14 对话已完成 TeachingUnit 字段决策。**R1 不重审字段本身**。

### M1. `prerequisites` 项目内 + 对象类型预留

- MCS 阶段先做项目内(同 `project_id` 内的依赖)
- 字段类型用 **对象 `list[TeachingUnitRef]`**(而非 `list[str]`)预留跨项目能力
- 校验:MCS 阶段 `TeachingUnitRef.project_id == current_project_id`,否则丢弃 + warning(详 § D8)
- LLM 建议的 prerequisites 必须**二次校验为现有 TeachingUnit.id**,失败丢弃(详 § D9)

### M2. `level` 三档由业务层决定

- `Literal["beginner", "normal", "advanced"]`
- 业务层映射:`normal` → DeepSeek V4-Flash;`advanced` → DeepSeek V4-Pro;`beginner` 预留
- 由 `TeachingLevelPolicy`(feature service 层)决定,**非 LLM 自决,非 API 路由 / middleware**(详 § D5 / D11)
- MCS 默认策略:未指定 → `normal`;显式 `advanced` 本任暂不开放,由 `TeachingLevelPolicy.resolve()` 抛 `UnsupportedTeachingLevelError`;V4-Pro + polling 留 X7

### M3. block 级 `knowledge_points / confusion_points` 按需生成(lazy)+ 缓存

- 不预生成所有 block;**用户交互触发**才即时生成,生成后缓存(详 § D7)
- **lazy 边界硬规则**:
  - 工程上传完成:**不生成任何 TeachingUnit**
  - 首屏导览(`GET /projects/{project_id}/overview`):**只返回 ProjectOverview 12 字段**,不预生成
  - 用户显式触发(点击 / API):按 target 生成一个 TeachingUnit
  - chat 命中某 target 且 cache 已存在:可读取作为 prompt supplemental context
  - chat 命中但无 cache:默认**不阻塞** chat 同步生成

### M4. `related_concepts` → `knowledge_points` 合并

v2.1 原 `related_concepts` 与 `knowledge_points` 语义重复;合并:删 `related_concepts`,新增 `knowledge_points`。TeachingUnit 字段:v2.1 原 11 字段 → 删 1 + 加 1 → **本任最终 11 字段**(详 § 7.3)。

### 7.4 `core/interfaces/teaching_unit_store.py`(新建,D15 / D19)

```python
# core/interfaces/teaching_unit_store.py
from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import Literal

from core.domain.teaching_unit import TeachingUnit


CacheKey = tuple[str, str, str, str, str, str, str, str]
# (project_id, target_type, target_id, level, builder_version, prompt_version, model_name, source_version)

CacheState = Literal["generating", "ready", "failed_retryable", "failed_permanent"]


@dataclass(frozen=True)
class TeachingUnitCacheRecord:
    """Store 层 stateful record;Service 按 state 分支处理。"""

    cache_key: CacheKey
    state: CacheState
    unit: TeachingUnit | None
    error_code: str | None
    retry_count: int
    expires_at: int


class TeachingUnitStore(ABC):
    """TeachingUnit 持久化 + 状态机契约。"""

    @abstractmethod
    async def get_record_by_key(self, cache_key: CacheKey) -> TeachingUnitCacheRecord | None:
        """命中返回完整 record;不命中返回 None。"""

    @abstractmethod
    async def begin_generating(self, cache_key: CacheKey, now: int, expires_at: int) -> bool:
        """尝试占位 state='generating';True = 本调用方负责生成,False = 他方占位中或 failed_permanent。"""

    @abstractmethod
    async def mark_ready(self, cache_key: CacheKey, unit: TeachingUnit) -> None:
        """state='generating' -> 'ready';写入 unit payload。"""

    @abstractmethod
    async def mark_failed(self, cache_key: CacheKey, error_code: str, retryable: bool) -> None:
        """state='generating' -> failed_retryable / failed_permanent;retry_count + 1。"""

    @abstractmethod
    async def list_ready_by_project(self, project_id: str) -> list[TeachingUnit]:
        """列出某 project 下所有 ready TeachingUnit。"""

    @abstractmethod
    async def delete_by_project(self, project_id: str) -> int:
        """级联清理,返回删除条数。"""
```

### 7.6 `features/overview/_teaching_unit_service.py`(新建)

```python
import asyncio
import time

from core.domain.exceptions import TeachingUnitGenerationError
from core.domain.teaching_unit import TeachingUnit
from core.interfaces.teaching_unit_store import (
    CacheKey,
    TeachingUnitCacheRecord,
    TeachingUnitStore,
)

from ._teaching_unit_builder import TeachingUnitBuilder, TeachingUnitBuildRequest

PROMPT_VERSION = "v0.1.0"
SOURCE_VERSION = "v1"  # D20:source_ref_schema_version 常量
TTL_SECONDS = 24 * 3600
MAX_RETRIES = 3
WAIT_TIMEOUT_SECONDS = 8


class TeachingUnitService:
    def __init__(self, store, builder, level_policy, model_name):
        self._store = store
        self._builder = builder
        self._level_policy = level_policy
        self._model_name = model_name
        self._inflight: dict[CacheKey, asyncio.Lock] = {}

    async def get_or_generate(self, request: TeachingUnitBuildRequest) -> TeachingUnit:
        resolved_level = self._level_policy.resolve(request)
        cache_key = self._build_cache_key(request, resolved_level)

        # Layer 1:读 record
        record = await self._store.get_record_by_key(cache_key)
        if record:
            check_result = self._check_record_state(record)
            if check_result is not None:
                return check_result

        # Layer 2:进程内锁
        lock = self._inflight.setdefault(cache_key, asyncio.Lock())
        try:
            async with lock:
                record = await self._store.get_record_by_key(cache_key)
                if record:
                    check_result = self._check_record_state(record)
                    if check_result is not None:
                        return check_result

                # Layer 3:SQLite optimistic insert
                now = int(time.time())
                expires_at = now + TTL_SECONDS
                won = await self._store.begin_generating(cache_key, now, expires_at)
                if not won:
                    return await self._wait_for_ready(cache_key)

                try:
                    unit = await self._builder.build(request, ...)
                    await self._store.mark_ready(cache_key, unit)
                    return unit
                except Exception as exc:
                    retryable = self._is_retryable(exc)
                    error_code = type(exc).__name__
                    await self._store.mark_failed(cache_key, error_code, retryable)
                    raise TeachingUnitGenerationError(
                        "教学单元生成失败,请刷新重试"
                    ) from exc
        finally:
            # R1 P1-7:lock 清理,防止 24h TTL 内累积锁对象
            self._inflight.pop(cache_key, None)

    def _check_record_state(self, record: TeachingUnitCacheRecord) -> TeachingUnit | None:
        now = int(time.time())
        if record.expires_at < now:
            return None
        if record.state == "ready" and record.unit is not None:
            return record.unit
        if record.state == "failed_permanent":
            raise TeachingUnitGenerationError("教学单元生成失败(已达最大重试),请稍后重试")
        if record.state == "failed_retryable" and record.retry_count >= MAX_RETRIES:
            raise TeachingUnitGenerationError("教学单元生成失败(已达最大重试),请稍后重试")
        return None
```
