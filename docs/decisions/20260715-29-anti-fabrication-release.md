# 决策 29: 反编造防线放宽 —— 内容放行,结构局部防御,安全隐私照旧 enforce

## 状态
✅ 决议 v0.2(2026-07-15,PM 拍板;v0.2 并入 R1+R6 双审:边界从"两分"精确为"三类")

★ **编号说明(防撞号)**:决策 26(本地优先研究工作台)、决策 28(效果判据)均已在决策序列占号但尚未入仓(待补)。本决策取 **29**,26 / 28 空位为已知缺口,编号不得复用。

★ **v0.1 → v0.2 改了什么**:v0.1 写"内容层放行 / 格式层防崩"两分。双审(R1 设计审 + R6 对 `origin/main@232bcc1` 可落核)证明两分不成立——会把私有引用外泄、把未核内容显示成"已验证论文来源"。v0.2 改为**三类边界**:内容判定放行,**结构完整性局部防御**,**安全/隐私/所有权照旧 enforce**。放行的是"内容判定",不是"一切"。

## 背景
产品对 LLM 输出做了两类事,一直没分清:格式层(JSON 结构、字段类型——防前端崩)与内容层(判缺口 / 无证据 / 无法验证 / 待确认 / 反编造 / 语义校验——判"能不能用")。内容层这套墙把 LLM 已生成的正确答案一条条挂问号,再把 build_steps 判废清成 null;前端一看没 build_steps 掉进推荐块 fallback,产品按自己口径 0 输出。

只读诊断实证(决策 15):头号缺口 `missing_parameter_value` 896 条阻塞里 488 条(54%)参数表里明明有值(匹配函数自己跟自己对不上判出来的);"generated=成功"只表示结构合法 JSON,三个自承认口径重算 229 轮 = 0/229;墙拦不住真编造(0.0006 死区照样带 `document_extracted` 标签过),却把正常参数弹走。净值为负。

## 决策
产品对 LLM 输出**只对内容判定放行**,LLM 给什么原样呈现当参考;编造(含哪类数据编造率高)靠内测反馈汇总定位再特化——**上线后测真值,不是上线前拦所有**。

落地分**三类**(与决策 27 收口,不打架):

1. **内容规则**(证据够不够、对不对、参数有无论文支持)→ **不再清空产物**,LLM 给什么留什么;改成写一条**带可区分子码的隐私安全日志**(哪条判定、哪一步、什么数据类型——不记参数值/摘录/正文)。这条日志是内测期定位高编造数据类型的抓手。
2. **结构 / 引用完整性规则**(重复 ID、`depends_on` 自环、连线指向不存在的 block、字段类型错、私有引用无法解析)→ **保留父级产物,局部去掉/降级坏字段**,不把坏关系塞给前端;**不整份清**。
3. **安全 / 隐私 / 所有权规则**(私有 `source_ref` 外泄、路径/秘密泄漏、危险 HTML、把 `user_supplied` 伪装成 `document_extracted`)→ **照旧确定性剥离/拒绝该字段,不放行**。

**格式层**(草稿 DTO / 解析层失败)按防崩兜底:**不硬 500、不白屏**,先尽量吐已解析部分,实在不行落现有 fallback;"出错就返空"不算合格。决策 27 的责任划线 / 草稿私有 `extra="forbid"` / 后端不读模型出处值 **全保留**。禁静默丢原则延续,后果从"判废清空"改"记日志 + 局部降级",子码仍须分辨真透传 vs 换名接着废。

**"原样透传"三层**:原始 completion 仅 eval-only 字节级存(生产不落);模型语义字段(标题/意图/步骤正文/连线说明)尽量保留;后端所有权字段(出处/ID/定位/source 类型/版本)仍由后端按不透明引用号重建,绝不照抄模型值。`source_ref` 未命中 → 保留步骤内容、evidence 降级/置空、**不给伪造"已验证论文"badge**。

## 理由
- **副驾定位**:产品帮 C 类学生完成复现的认知工作,当参考意见,不替他判对错;精确搭建/跑通/收敛由用户自己在 MATLAB 完成(宪法 § 2 + 决策 22 § 1.1)。把关"能不能用"不是副驾的活——但**保护用户隐私、不泄私有引用、不拿假章骗人,是产品的底线,不在放行范围**。
- 上线前的内容墙对真编造无效(0.0006 照样过)、对正常数据有害(54% 误判),留着只换来 0 输出。
- 编造率按数据类型分布不均,靠真值反馈定位再特化,不靠一道拦所有的墙。
- 放行只把地板垫到跟 GPT 直出打平;真正优于 GPT 靠"参数落到出处且落对"(下一张参数卡),不靠这道墙——而 badge 盖章(章真才盖)正是这条护城河的前脸。
- 效果判据(决策 28):放行后判效果只认同场配对 + null≠0 + 坏事件配分母,N≥3 报分布。

## 影响范围
- **覆盖**此前多张卡里"反编造防线不得放宽 / 无证据必须降级 / 语义校验失败须判废"的红线文字 —— 本决策起,**内容层那些红线作废**;结构完整性改局部防御,安全隐私照旧 enforce,格式层防崩保留。落地卡 **TASK-538 v0.2**。
- **不影响**宪法 § 9 证据双源标注(`document_extracted` / `user_supplied` 仍分开标)与不记用户内容硬约束。放行的是"判废清空"的后果,不是"取消来源标注"或"放宽隐私"——来源标注本身是产品优于 GPT 的核心,反而要修对(参数拼接 bug,单列)。
- **不改对外 JSON schema**(行为契约有意变更,单独标注)。
- R1 设计审严重度校准:今后"内容判定 → 清空产物"作为默认反模式排查项;并须逐分支区分 content / structure / security,禁按 validator 名一刀切。
