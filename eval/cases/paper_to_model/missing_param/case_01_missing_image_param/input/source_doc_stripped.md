## 1. 任务陈述

利用 MATLAB 对突然三相短路后的定子电流、转子电流过程进行数值计算分析。

---

## 2. 电机参数与工况

假设一台有阻尼绕组同步发电机,参数如下:

- 额定有功功率 PN = 200 MW
- 额定电压 UN = 13.8 kV
- 额定频率 fN = 50 Hz
- d 轴同步电抗 xd = 1.0
- q 轴同步电抗 xq = 0.6
- d 轴暂态电抗 xd' = 0.3
- d 轴次暂态电抗 xd'' = 0.21
- q 轴次暂态电抗 xq'' = 0.31
- 定子电阻 r = 0.005
- 励磁绕组漏抗 xσf = 0.18
- d 轴阻尼绕组互漏抗 xaD = 0.1
- q 轴阻尼绕组漏抗 xσQ = 0.25
- d 轴开路暂态时间常数 Td0' = 5 s
- d 轴阻尼时间常数 TD = 2 s
- q 轴开路次暂态时间常数 Tq0'' = 1.4 s

工况:发电机空载,端电压为额定电压,端子突然发生三相短路。

---

## 3. 数值计算公式

利用 MATLAB 对突然三相短路后的定子电流进行数值计算的基本步骤如下:

(1)假定已知各衰减时间常数,利用定子电流的 d 轴和 q 轴分量经过变换和整理得到的定子 a 相电流为:

```
ia = -cos(ωt+α0) - 1.4·e^(-2.97t)·cos(ωt+α0) - 2.34·e^(0.608t)·cos(ωt+α0) + 4·e^(-6.3t)·cos(-α0) + 0.77·e^(-6.3t)·cos(2ωt+α0)
```

(2)对以上公式采用 `.m` 文件进行数值计算和绘图。绘图包括发电机端突然三相短路时的 a 相定子电流,以及基频分量、倍频分量和非周期分量波形。

---

## 4. 物理含义讲解

同步电机突然三相短路,基频周期分量从短路电流有效值衰减至稳态值。非周期分量从短路电流初始值衰减至 0,倍频分量从短路电流初始值按指数规律衰减至 0。

---
